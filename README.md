# 每日库存记录

每天工作结束后，把当天的库存情况保存为 Markdown 文件，放进[对应年份文件夹](2026/README.md)。例如 2026 年 10 月 24 日的文件路径是 `2026/20261024.md`。

首页的日期索引会在上传后自动更新：当年记录全部显示，日期从新到旧；往年记录折叠，点击年份即可展开。每日文件始终保存在仓库中。GitHub 的文件夹列表仍按平台默认顺序显示，请从本页按日期浏览。

只识别年份文件夹下以 `YYYYMMDD.md` 命名、且日期真实有效的文件。文件内容由你自行记录；自动更新程序只修改本页索引。
